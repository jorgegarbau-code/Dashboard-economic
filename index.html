    Cómo recopilar noticias

    Ejecuta la recopilación en GitHub para incorporar titulares nuevos.

    1. Abre Actions en el repositorio de GitHub.
    2. Selecciona Actualizar noticias y publicar dashboard.
    3. Pulsa Run workflow y confirma con Run workflow.
    4. Cuando termine la publicación, pulsa Refresh aquí para leer el archivo publicado.
